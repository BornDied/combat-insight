# Combat Insight

Combat Insight is a RuneLite plugin for viewing live combat calculations while playing Old School RuneScape.

## Features

Combat Insight currently provides:

- Maximum hit calculations
- Hit chance against your current target
- Estimated damage per second
- Attack speed information
- Target-aware combat calculations
- Support for your current equipment, combat style, prayers, boosts, and target

## How to use

1. Install Combat Insight from the RuneLite Plugin Hub.
2. Enable the plugin in RuneLite's plugin panel.
3. Equip your gear and set your combat style.
4. Select or attack an NPC.
5. View the calculated combat information in the overlay.

The displayed values update when your equipment, combat style, prayers, boosts, weapon, or target changes.

## Understanding the overlay

### Max hit

The highest possible damage your current setup can deal with a successful hit.

### Hit chance

The estimated chance that your current attack will successfully hit the target.

### DPS

Your estimated average damage per second based on your current equipment, attack speed, accuracy, damage, and target.

### Attack speed

The number of game ticks between your attacks.

### Target information

Calculations are based on the NPC you are currently fighting whenever target information is available.

## Troubleshooting

If the displayed values seem incorrect:

1. Confirm that your equipment is correct.
2. Check your combat style.
3. Check your active prayers and boosts.
4. Confirm that the correct NPC is selected or targeted.
5. Reload the plugin if RuneLite has not updated the displayed information.

If the problem continues, please report it on GitHub with:

- Your equipment
- Combat style
- Active prayers and boosts
- Target NPC
- The value you expected
- The value Combat Insight displayed
- Any relevant screenshots or logs
